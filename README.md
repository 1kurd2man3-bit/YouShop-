# YouShop — فروشگاه اینترنتی فارسی

نمونه اولیه فروشگاه راست‌چین با جست‌وجو، دسته‌بندی، سبد خرید، ثبت سفارش و پنل مدیریت محصولات و سفارش‌ها.

## اجرای روی لپ‌تاپ
1. نصب Node.js نسخه 18 یا جدیدتر از https://nodejs.org
2. فایل ZIP را استخراج کنید.
3. در پوشه پروژه ترمینال باز کنید و اجرا کنید:
   ```bash
   npm install
   npm start
   ```
4. در مرورگر باز کنید: http://localhost:3000
5. پنل مدیریت: http://localhost:3000/admin

## ورود اولیه پنل مدیریت (فقط برای اجرای محلی)
- رمز عبور پیش‌فرض: `ChangeThisPassword123!`
- پیش از انتشار عمومی، حتماً متغیرهای محیطی `ADMIN_PASSWORD` و `ADMIN_SECRET` را با مقادیر قوی و منحصربه‌فرد تنظیم کنید. رمز پیش‌فرض را روی سایت عمومی استفاده نکنید.
